Arrow functions – practical & edge‑case revision

One file · All syntax · Real‑world usage · Browser & console gotchas

1. The two bodies: expression vs block

const fn = (a, b) => a + b; — implicit return, no braces, single expression.

const fn = (a, b) => { return a + b; }; — block body, explicit return. 

// expression body (implicit return)
const add = (a, b) => a + b;

// block body (explicit return needed)
const multiply = (a, b) => {
  const result = a * b;
  return result;
};
⚡ Rule of thumb: omit braces for one-liners; use braces when you need multiple statements or side effects.

2. Parameters: zero, one, many, defaults, rest

Zero parameters

const sayHi = () => 'Hi!';
console.log(sayHi()); // Hi!

One parameter (no parens needed)

const double = n => n * 2;
console.log(double(5)); // 10

Multiple parameters

const join = (a, b, c) => `${a}-${b}-${c}`;
console.log(join('x','y','z')); // x-y-z

Default parameters

const greet = (name = 'Guest') => `Hello, ${name}`;
console.log(greet());      // Hello, Guest
console.log(greet('Dev')); // Hello, Dev

Rest parameters (...args)

const sumAll = (...numbers) => numbers.reduce((acc, n) => acc + n, 0);
console.log(sumAll(1, 2, 3, 4)); // 10

3. Real‑life practical usage

Array methods – map, filter, reduce

const nums = [1, 2, 3, 4, 5];
const squares = nums.map(n => n * n);          // [1, 4, 9, 16, 25]
const evens = nums.filter(n => n % 2 === 0);   // [2, 4]
const total = nums.reduce((s, n) => s + n, 0); // 15

Event handlers (with browser DOM)

button.addEventListener('click', () => {
  console.log('Clicked!');
  // no `this` binding needed – arrow uses outer scope
});

Promises & async (fetch, timers)

fetch('/api/data')
  .then(res => res.json())
  .then(data => console.log(data))
  .catch(err => console.error(err));

setTimeout(() => console.log('2 seconds'), 2000);

Inline callbacks with sort

const people = [{name:'Zoe', age:30}, {name:'Adam', age:25}];
people.sort((a, b) => a.age - b.age); // ascending

4. Key differences & pitfalls edge cases

❌ No own this – inherits from enclosing scope

const obj = {
  name: 'Object',
  regular: function() {
    console.log(this.name); // 'Object'
  },
  arrow: () => {
    console.log(this.name); // undefined (or window.name in browser)
  }
};
obj.regular(); // Object
obj.arrow();   // undefined
⚠️ Never use arrow functions as object methods if you rely on this. Also avoid for event listeners that need this to reference the element.

❌ No arguments object

const regular = function() { return arguments.length; };
console.log(regular(1, 2, 3)); // 3

const arrow = () => arguments.length; // ReferenceError (or outer arguments)
// Use rest params instead: (...args) => args.length

❌ Cannot be constructors (new throws)

const Person = (name) => { this.name = name; };
// new Person('Ana'); // TypeError: Person is not a constructor

❌ No prototype property

const fn = () => {};
console.log(fn.prototype); // undefined

❌ Not hoisted like declarations

// console.log(arrowFn()); // ReferenceError: Cannot access before initialization
const arrowFn = () => 'hi';

// But function declarations are hoisted:
console.log(declFn()); // 'hello'
function declFn() { return 'hello'; }

✅ Great for callbacks where this should be lexical

const counter = {
  count: 0,
  start() {
    setInterval(() => {
      this.count++; // `this` is counter (lexical)
      console.log(this.count);
    }, 1000);
  }
};
// counter.start();

5. Browser vs Console quirks environment

  • Browser top‑level: this inside an arrow at global scope is window (same as regular this).
  • Console (DevTools): When you type an arrow function at the top level, this is usually the window object too. But inside a module or strict mode, it's undefined.
  • Strict mode: Arrow functions don't have their own this, so it's taken from the enclosing lexical scope – which in strict global code is undefined.
  • Node.js (console/REPL): Top‑level this is module.exports (or global in some contexts).

6. When to use arrow (cheat sheet)

✅ Use arrow

  • Array callbacks (map, filter, reduce)
  • Promises .then() / .catch()
  • Timers (setTimeout, setInterval)
  • Event handlers when you don’t need this
  • Short one‑liners, currying
  • When you want lexical this

❌ Avoid arrow

  • Object methods that use this
  • Constructors (new)
  • When you need arguments object
  • Prototype methods
  • Event listeners that rely on this (e.g., jQuery)

7. Syntax edge cases – things that break

Returning object literals (use parentheses)

// ❌ Syntax error: ambiguous with block
// const makeUser = () => { name: 'Ana' };

// ✅ Wrap in parentheses for implicit object return
const makeUser = () => ({ name: 'Ana', age: 25 });
console.log(makeUser()); // { name: 'Ana', age: 25 }

Immediately invoked arrow function (IIFE)

(() => {
  console.log('IIFE arrow');
})();

Arrow with ternary / short‑circuit

const isEven = n => n % 2 === 0 ? 'even' : 'odd';
const defaultName = name => name || 'anonymous';

Nested arrows (currying)

const add = a => b => c => a + b + c;
console.log(add(1)(2)(3)); // 6
